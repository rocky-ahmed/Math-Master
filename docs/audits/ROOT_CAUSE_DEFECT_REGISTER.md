# Math Master — Root-Cause Defect Register (`BUG-01` through `BUG-21`)

## 1. Executive Summary
This register documents all **21 root-cause engineering defects** (`BUG-01` through `BUG-21`) identified, fixed, and regression-tested across the Math Master Android codebase (`com.aistudio.applet.ghqqzu`). Every defect has a verified code fix in `app/src/main/java/com/example/` and automated unit/Robolectric regression test coverage in `app/src/test/java/com/example/`.
