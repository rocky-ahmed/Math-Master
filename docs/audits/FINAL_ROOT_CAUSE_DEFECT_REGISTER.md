# Math Master — Final Root-Cause Defect Register (`BUG-01` – `BUG-35`)

This unified register reconciles all historical engineering defects (`BUG-01` through `BUG-28`) across previous audit phases with the **7 newly discovered and resolved defects (`BUG-29` through `BUG-35`)** from the final independent adversarial bug hunt and regression validation.

## 3. Independent Adversarial Bug Hunt Defects (`BUG-29` – `BUG-35`) — Verified Resolved

| ID | Severity | Module / File | Root Cause Analysis | Fix Implemented & Verified |
| :--- | :--- | :--- | :--- | :--- |
| **`BUG-29`** | **P1 (High)** | Shared Math Engine (`SharedMathEngine.kt`) | `stripCommonUnitSuffixes()` stripped dotted units (`"সে.মি."`, `"কি.মি."`, `"মি."`) but omitted dotless textbook units (`"সেমি"`, `"বর্গসেমি"`, `"ঘনসেমি"`, `"মিটার"`, `"বর্গমিটার"`, `"কিমি"`). Additionally, `normalizeAnswerToken()` stripped all spaces prior to fraction evaluation, turning mixed fractions (`"1 1/2"`, `"১ ১/২"`, `"১ সমস্ত ১/২"`, `"১ পূর্ণ ১/২"`) into `"11/2"` instead of `"3/2"`. | Expanded `stripCommonUnitSuffixes()` with iterative longest-first matching for all dotted and dotless textbook units, and converted mixed fractions to improper fractions `"a/b"` inside `normalizeAnswerToken()` before stripping whitespace. Verified by `adversarialAudit_bug29_dotlessUnitSuffixesAndMixedFractionEquivalence`. |
| **`BUG-30`** | **P1 (High)** | Algebraic Simplification (`SharedMathEngine.kt`) | `SharedMathEngine.simplify()` documented support for distributive parenthesized expressions (`2(x + 3) + 4x - 1`), but `parseQuadraticExpression()` did not expand `k(ax + b)` or `±(ax + b)`, falling through to `solveArithmetic()` which failed on variable `x`. | Added `expandAlgebraicParentheses()` to expand distributive single-variable linear and quadratic parentheses and emit an explicit distributive expansion step in `simplify()`. Verified by `adversarialAudit_bug30_parenthesizedDistributiveAlgebraicSimplification`. |
| **`BUG-31`** | **P1 (High)** | Book Mistake & Spaced Revision (`MathRepository.kt`, `MathViewModel.kt`) | `deleteBookMistake(questionId)` called `deleteBookSpacedRevisionById("mistake_$questionId")`, which became `"mistake_mistake_<id>"` when `questionId` already had a `"mistake_"` prefix, leaving orphaned rows in `book_spaced_revision`. Furthermore, answering a Book question correctly in `submitBookPracticeAnswer()` resolved `unified_mistake_notebook` (`"BOOK_<id>"`) without resolving `book_mistakes` (`"mistake_<id>"`), and `recordBookQuestionMistake`/`markBookMistakeResolved`/`deleteBookMistake` did not synchronize `unified_mistake_notebook`. | Normalized `rawId` and `revItemId = "mistake_$rawId"` across `recordBookQuestionMistake`, `markBookMistakeResolved`, and `deleteBookMistake`, synchronized all three methods with `unified_mistake_notebook` (`"BOOK_$rawId"`), and called `markBookMistakeResolved` in `submitBookPracticeAnswer()` when `isCorrect == true`. Verified by `adversarialAudit_bug31_and_bug32_crossTableMistakeSyncAndResolution`. |
| **`BUG-32`** | **P1 (High)** | BCS & Quiz Mistake Sync (`MathRepository.kt`, `MathViewModel.kt`) | BCS exam questions generated with mode-specific prefixes (`"bcs_exam_1_<id>"`, `"bcs_prev_1_<id>"`, `"bcs_mistake_retry_1_<id>"`, `"bcs_ma_exam_1_<id>"`) failed to match canonical question IDs when retried in `MISTAKE_PRACTICE` or Question Bank. Additionally, `submitQuizAnswer()`, `finishQuizSession()`, `recordBcsMistake()`, `markBcsMistakeResolved()`, and `deleteBcsMistake()` did not synchronize with `unified_mistake_notebook`. | Added `extractCanonicalBcsQuestionId()` in `MathRepository` to strip mode/index prefixes and `_rep_` suffixes, synchronized `recordBcsMistake`/`markBcsMistakeResolved`/`deleteBcsMistake` with `unified_mistake_notebook` (`"BCS_${profileId}_$rawQId"`), and wired `submitQuizAnswer()` and `finishQuizSession()` to record/resolve mistakes across both tables. Verified by `adversarialAudit_bug31_and_bug32_crossTableMistakeSyncAndResolution`. |
| **`BUG-33`** | **P2 (Medium)** | Interactive Quiz State (`MathViewModel.kt`) | In non-`isFullExamMode` quizzes (`TOPIC`, `TIMED`, `PRACTICE`, `MIXED`), selecting an option or typing a numerical answer without pressing "উত্তর যাচাই করুন" only updated transient `selectedOptionIndex`/`typedAnswer`. Jumping to another question via palette or `previousQuizQuestion()` lost the unsubmitted draft, and timer expiry in `QuizMode.TIMED` dropped unsubmitted drafts on earlier visited questions. | Added `pendingOptionSelections` and `pendingTypedAnswers` to `QuizSessionState`, restored pending drafts in `jumpToQuizQuestion`/`previousQuizQuestion`/`nextQuizQuestion`, and merged pending drafts in `finishQuizSession()`. Verified by `adversarialAudit_bug33_and_bug34_unsubmittedDraftPreservationAndSkippedWeakTopics`. |
| **`BUG-34`** | **P2 (Medium)** | Exam Scoring Engine (`ExamEngineModels.kt`) | `ExamScoringEngine.evaluateExam()` classified any topic with `accuracyPercent < 65.0` as a `weakTopic` even when `attemptedCount == 0` (all questions in that topic were skipped with `0` wrong answers), contradicting `strongTopics` which required `attemptedCount > 0`. | Added `it.attemptedCount > 0` guard to `weakTopics` filter in `ExamScoringEngine.evaluateExam()`. Verified by `adversarialAudit_bug33_and_bug34_unsubmittedDraftPreservationAndSkippedWeakTopics`. |
| **`BUG-35`** | **P2 (Medium)** | Book PDF Reader (`BookReaderAndLabsScreens.kt`) | `BookPdfReaderScreen` allocated `ARGB_8888` bitmaps without the `Mutex` + `LruCache(12)` + `RGB_565` safeguard documented in `BUG-01`, and `resolveOfflinePdfFile()` wrote to a shared `cached_${bookId.id}.pdf.tmp` without synchronization. | Implemented `BookPdfRenderCache` (`Mutex` + bounded `LruCache<String, Bitmap>(12)` + `Bitmap.Config.RGB_565` + OOM cache-eviction fallback) and synchronized atomic temp-file extraction in `resolveOfflinePdfFile()`. Verified by `adversarialAudit_bug35_pdfRenderCacheAndSynchronizedOfflinePdfExtraction`. |
